# 2. Readiness is the lower bound of a Wilson interval

A pilot scores agents on 20 to 40 past tenders. "9 of 10 right" is not 90 %. Each agent's level comes from
the lower bound of a 95 % Wilson interval on its key metric against two bars (assist 0.75, automate 0.90,
`config/workbench.yaml`), with a minimum number of scored items below which it is "too few tenders".
The value case uses the level, so an agent that is not ready contributes nothing, whatever a demo showed.
